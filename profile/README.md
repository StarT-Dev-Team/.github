# 🌟 Star Technology

Welcome to the **StarT Dev Team** organization.

We are a development team focused on creating a **Minecraft 1.20.1 modpack** centered around technology, progression, and high-quality modded gameplay.

This organization hosts all official repositories related to the **Star Technology project**, including our modpack, core mods, tooling, and documentation.

---

## 📂 Key Repositories

| Repository | Description |
|-----------|------------|
| [Star-Technology](https://github.com/StarT-Dev-Team/Star-Technology) | Main modpack repository |
